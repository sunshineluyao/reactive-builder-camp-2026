# 三种常用构图

[English](layout-recipes.md) · **简体中文**

| 读者想知道什么 | 怎样构图 | 需要哪些证据 |
| --- | --- | --- |
| 规则触发会改变什么？ | 将两个实际输入画在同一刻度，标出判断边界，末端呈现已记录的结果。 | 单位、是否包含边界，以及可检查的回执、样本或日志。 |
| 系统怎样组织？ | 一侧放输入对象，中间将最大空间留给关键操作，末端交代谁控制或验证结果。 | 标明哪些组件已经演示，哪些仍处于设计阶段。 |
| 这份数据或比较能说明什么？ | 放大真实样本或一对测量值，只标注解释发现所需的特征，写明范围与来源。 | 单位、样本或版本、观测时段，以及示例来源。 |

## 建立一套简明的视觉规则

- 用大小、粗细、位置和留白决定阅读顺序。各元素可以共享一张底图，重点区域应有更高权重。
- 外边距宽于内边距，为箭头、标签留出通道。让标题、图形和证据共用对齐线，再以缩略图确认视线首先落在哪里。
- 选底色、稍亮的承托面、主文字、次文字和至多三种有意义的强调色，务必与实际底色比较。普通文字目标对比度 4.5:1，大字或关键图形 3:1。用文字、空实或形状让色觉不同的读者也能识别。
- 设计属于题材的符号，如平价波动带、样本轮廓或传感器覆盖范围。必要时标明假设图与示例数据。
- 手机版调整阅读方向，缩短行长，保留理解结果必需的限制，旁边放直接打开竖图的链接。

## 三次查看

1. 看缩略图，第一次接触项目的人能认出主题和重点吗？
2. 在正常电脑和手机宽度下，能读懂证据、决定与单位吗？
3. 打开附近的链接，能核实哪些是观测结果，哪些是项目目标吗？

## 在实际尺寸下配色与绘图

对技术首图，可用近黑梅紫 `#100D20` 作底，较亮的 `#261937` 托起中心区域。用青绿 `#47E6D2` 标记证据、淡紫 `#C49AFF` 标记中间判断、少量琥珀色 `#FFCA69` 标记结果，正文以柔白 `#F5F1FB` 排印。让少量高饱和颜色沿边线、标记和对应的证据重复出现。关键机制后的一片柔光即可营造纵深。连续色带和曲线应对应真实测量。

档案或自然史题材也可以使用暖纸色、深墨色、一种冷色批注和一个明亮的标本标记。先画出专业读者认得的轮廓，再用几条精确的线解释对象怎样运作，并在实际底色上检验对比度。
